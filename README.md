# 🖥️ TheWatch-Web

> Enterprise Web Portals, Blazor Command Center, and Operational Dispatch Dashboards for The Watch.

---

## 📦 Projects in this Repository

| Project / Component | Description |
| :--- | :--- |
| **`TheWatch.Web.Admin`** | Radzen Blazor Interactive Server/WebAssembly Admin Portal for emergency management directors, incident commanders, and compliance auditors. |
| **`TheWatch.UI.RazorComponents`** | Rich library of reusable Razor components, incident timeline widgets, geospatial map overlays, and alarm banners. |
| **`TheWatch.Catalog.Experience`** | Auto-generated responsive UI catalog pages and design system components. |
| **`wwwroot/` & `cloudflare/`** | Static web assets, edge functions, and Cloudflare Pages deployment manifests. |

---

## 🛠️ Local Development & Running

```bash
# Run the Web Admin Portal locally
dotnet run --project TheWatch.DotNet/src/Clients/TheWatch.Web.Admin/TheWatch.Web.Admin.csproj
```
